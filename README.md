# Saboit Games — protótipo responsivo

Protótipo em HTML, CSS e JavaScript para apresentar a identidade visual da Saboit Games.

## Conteúdo
- Tela inicial com a fotografia do quarto gamer e interface sobre a TV.
- Botão START que abre o catálogo demonstrativo.
- Catálogo fictício com 12 jogos em capas ilustrativas criadas em CSS.
- Busca por título e filtros por plataforma.
- Layout adaptado para computador e celular.

## Importante
Todos os títulos, capas, preços e disponibilidades do catálogo são fictícios e servem apenas para demonstrar o visual. Os botões "Ver anúncio" exibem um aviso; links reais de Mercado Livre, Shopee, OLX e WhatsApp serão cadastrados depois.

## Como testar
Abra `index.html` no navegador. Para publicar no GitHub Pages, mantenha `index.html`, `style.css`, `script.js` e a pasta `assets` na raiz do repositório.
