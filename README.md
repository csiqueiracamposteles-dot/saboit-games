# Saboit Games — protótipo locadora retrô

Protótipo responsivo em HTML, CSS e JavaScript.

## Estrutura
- `index.html`: tela de entrada e tela da locadora.
- `style.css`: visual retrô, responsividade e capas ilustrativas.
- `script.js`: navegação, busca, filtros e fichas dos jogos.
- `assets/quarto-saboit.png`: fotografia original usada na primeira tela.

## Experiência
1. A primeira tela mantém o quarto gamer original, com SABOIT GAMES e START sobre a área da TV.
2. Ao clicar em START, o visitante entra em uma locadora retrô com balcão, letreiro e prateleiras de jogos físicos.
3. O acervo demonstrativo tem 12 jogos fictícios, capas criadas em CSS, busca e filtros por plataforma.
4. Ao selecionar um jogo, abre uma ficha com preço demonstrativo.
5. O botão de consulta informa que os anúncios são fictícios até serem substituídos por produtos reais.

## Testar
Abra `index.html` no navegador. Para publicar no GitHub Pages, mantenha `index.html`, `style.css`, `script.js` e a pasta `assets` na raiz do repositório.

## Importante
Os nomes, capas, preços e disponibilidades são fictícios. Não representam anúncios reais. A foto do quarto foi mantida como arquivo local do projeto.
